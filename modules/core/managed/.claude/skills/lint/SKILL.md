# /lint · 知识库体检

`$PY` 指 `.kb.json` 中 `python` 字段的值。

1. 运行 `$PY scripts/kb.py lint`，得到机械检查的结果。
2. 做内容检查。这部分脚本做不到，抽查即可，不需要通读全库：
   - hot.md、roadmap 和最近几份纪要是否一致；有没有过时的"当前重点"；有没有已经完成但还没勾掉的任务。
   - wiki 页之间是否有相互矛盾的论断；有没有缺少来源的论断。
   - 状态为"待定"的决策，是否其实已经在后来的讨论中做出了决定。
3. 分类处理：
   - 可以直接修的问题直接修，例如死链改名、补 frontmatter、登记资料。
   - 涉及删除内容或改变结论的问题，先列出来，请用户确认后再改。
   - 未归档的会话，建议运行 `/wrapup`。
4. 修复后重新运行 `$PY scripts/kb.py lint` 和 `$PY scripts/kb.py index`。如果有改动，提交 `lint: 修复摘要`。
